# Module voix

Voix vers texte (texte reconnu affiché avant traitement) et texte vers voix, dans les 8 langues ; micro et lecture activables à tout moment ; consentement avant le micro, audio non conservé.

| | |
|---|---|
| **Exigences** | BF7, BF8, BF9, BF13, BNF3, BNF7, BNF8 |
| **Contrat** | Modèles locaux à mesurer (ex. whisper-tn-ct2 pour le tunisien, Apache-2.0) ; l'arabizi est converti en lettres arabes avant la synthèse vocale. |
| **S'appuie sur** | moteurs, langue |
| **État** | À faire. |
